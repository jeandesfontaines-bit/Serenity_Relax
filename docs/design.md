# Design System — Serenity Relax / Studio Board

## 1. Philosophie de Design

**"Calme premium, clarté moderne et douceur thérapeutique"**

Le design doit transmettre :
- Sérénité et professionnalisme
- Douceur sans être infantiliste
- Modernité épurée avec une touche humaine et chaleureuse
- Sentiment de luxe accessible (bien-être haut de gamme)

## 2. Palette de Couleurs

### Primary
- **Violet Électrique / Indigo** (`#6366F1` ou `#5B21B6`) : accent principal (boutons, icônes actives)
- **Vert Menthe / Lime doux** (`#A3E635` ou `#84CC16`) : positif, disponible, succès

### Neutres
- **Fond principal** : `#F8F9FA` ou `#FAFBFC` (très clair)
- **Cartes / Surfaces** : `#FFFFFF` avec légère ombre douce
- **Texte principal** : `#1F2937`
- **Texte secondaire** : `#64748B`
- **Bordures** : `#E2E8F0`

### Statuts
- **Payé / Honoré** : `#22C55E` (vert doux)
- **En retard / À régler** : `#F59E0B` (orange chaleureux)
- **Annulé / Indisponible** : `#EF4444` (rouge doux)

### Autres
- **Aromathérapie** : teintes violettes/lavande
- **Réflexologie** : teintes roses/terracotta douces

## 3. Typographie

- **Heading** : `Inter` ou `Satoshi` — Semi-bold / Bold
- **Body** : `Inter` — Regular / Medium
- **Tailles** :
  - H1 : 28–32px
  - H2 : 22–24px
  - H3 : 18–20px
  - Body : 15–16px
  - Small : 13–14px

## 4. Style des Composants

### Cards
- Coins arrondis : `20px` (généreux)
- Ombre très douce : `0 4px 20px -2px rgb(0 0 0 / 0.06)`
- Padding interne confortable (`24px`)

### Boutons
- **Primary** : violet avec hover lumineux
- **Secondary** : fond blanc + bordure fine
- **Ghost** : uniquement texte + icône
- Coins arrondis : `12px` ou `9999px` (pill) selon contexte
- Hauteur : `48px` minimum

### Badges & Tags
- Coins très arrondis (`9999px`)
- Petits et légers
- Couleurs douces selon statut

### Navigation
- Icônes modernes (Lucide ou Feather style)
- Sidebar fixe avec icônes + labels
- Highlight actif avec violet + léger fond

## 5. Espacement & Grille

- **Base unit** : `8px`
- Padding des pages : `32px`
- Gap entre cartes : `24px`
- Utilisation généreuse de l’espace blanc (breathing room)

## 6. Micro-interactions

- Hover subtil (scale 1.02 + ombre plus forte)
- Transitions `cubic-bezier(0.4, 0, 0.2, 1)` (très smooth)
- Apparition des cartes en fade-up léger
- Feedback visuel immédiat sur les boutons

## 7. Direction Visuelle Globale

- **Soft UI** avec un peu de **Glassmorphism** sur certains overlays
- Gradients très subtils (presque imperceptibles) sur les accents
- Illustrations et icônes en style **3D soft** ou **line icon** moderne
- Utilisation de formes organiques (cercles, blobs doux) pour les états "libre/journée calme"

## 8. Dark Mode (optionnel futur)

Prévoir une variante sombre élégante avec violet plus profond et fonds `#0F172A`.
