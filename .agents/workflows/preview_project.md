# Preview Project

// turbo-all

## Steps

1. Install dependencies (if not already installed):
```bash
npm install
```

2. Start the development server:
```bash
npm run dev -- --port 3000
```

3. Open **http://localhost:3000** in your browser to preview the application.

The dev server uses Next.js 15 with Turbopack for fast refresh. The app will be available at port 3000.
